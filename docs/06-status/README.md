# Platform Implementation Status & Quality Assurance

This directory is intended to provide evidence-backed status reports, tracking registers, and acceptance matrices. The current registers contain inconsistencies and are under reconciliation; treat completion labels and test counts as unverified until checked against current source and reproducible verification evidence. See the [staged review plan](../07-in-development/codebase-review-plan.md).

---

## Status Registers

| Register                                      | Purpose                                      | Key Content                                                                                          |
| :-------------------------------------------- | :------------------------------------------- | :--------------------------------------------------------------------------------------------------- |
| **[Current State](./current-state.md)**       | Current implementation claims, to be audited | Subsystem descriptions and cited evidence; validate dates, counts, and claims before relying on them |
| **[Roadmap](./roadmap.md)**                   | Phased development direction                 | Planned sequence; reconcile with current implementation and review findings                          |
| **[Work Packages](./work-packages.md)**       | Implementation tracking register             | WP IDs and status claims; reconcile against source, tests, and CI                                    |
| **[Acceptance Gates](./acceptance-gates.md)** | Quality criteria and status claims           | Gate IDs and evidence; reconcile identifiers and completion state                                    |
